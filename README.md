# 🍔 GoodFood Web Application

GoodFood is a responsive web-based application designed to help users explore food menus, view details, and make informed dining decisions through a simple and intuitive interface.

## 👩‍💻 My Role
Front-End Developer & UI Designer (Team Project)

---

## 🚀 Tech Stack
- HTML5
- CSS3
- JavaScript
- Figma (UI/UX Design)

---

## 🎯 The Challenge
Designing a user-friendly food discovery website that works seamlessly across devices while maintaining clean navigation, readable layouts, and scalable front-end architecture for future feature expansion.

---

## 💡 The Solution
- Built responsive layouts using semantic HTML and modular CSS
- Implemented interactive features using JavaScript
- Designed UI flow and wireframes in Figma
- Applied consistent styling and reusable components
- Ensured mobile-first and responsive design principles
